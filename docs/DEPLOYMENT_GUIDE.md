# دليل النشر والتطوير

## المتطلبات الأساسية

- Node.js 16.x أو أعلى
- npm أو yarn
- Git

## إعداد البيئة المحلية

### 1. استنساخ المستودع
```bash
git clone <repository-url>
cd imperium-gate-ai
```

### 2. تثبيت الاعتمادات
```bash
npm install
```

### 3. إعداد متغيرات البيئة
انسخ ملف `.env.example` إلى `.env.local` وقم بتحديث القيم:

```bash
cp .env.example .env.local
```

### 4. تشغيل التطبيق في وضع التطوير
```bash
npm run dev
```

## بناء التطبيق للإنتاج

### إنشاء البناء النهائي
```bash
npm run build
```

### تشغيل التطبيق في وضع الإنتاج
```bash
npm start
```

## نشر التطبيق

### باستخدام Vercel
1. قم بربط المستودع مع Vercel
2. قم بتكوين متغيرات البيئة في لوحة التحكم
3. قم بالنشر التلقائي مع كل تحديث

### باستخدام Docker
```bash
# بناء الصورة
docker build -t imperium-gate-ai .

# تشغيل الحاوية
docker run -p 3000:3000 imperium-gate-ai
```

## إعدادات إضافية

### تكوين OpenRouter API
تأكد من إعداد المفتاح التالي في متغيرات البيئة:
```
OPENROUTER_API_KEY=your_api_key_here
```

### تكوين Gemini AI
للاستخدام مع Gemini:
```
GEMINI_API_KEY=your_gemini_key_here
```

## استكشاف الأخطاء وإصلاحها

### مشاكل الشبكة
- تحقق من اتصال الإنترنت
- تأكد من صحة مفاتيح API
- راجع سجلات الكونسول للحصول على تفاصيل الأخطاء

### مشاكل الأداء
- قم بمسح الكاش: `npm run clean`
- أعد تثبيت الاعتمادات: `rm -rf node_modules && npm install`
